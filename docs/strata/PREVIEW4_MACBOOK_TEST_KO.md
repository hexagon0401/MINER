# STRATA Preview 4 — 사용자 MacBook 시험

이 패키지는 정식 2.0.0이 아닙니다. 실제 WARP·학교망·LoL 통계창의 해결 여부는 아직 미검증입니다. 설치 전에 기존 ALPHA 1.2.3 DMG와 설정을 보관하세요. ALPHA와 STRATA를 동시에 실행하지 마세요.

## 설치와 연결

1. 기존 MINER에서 **중지**를 누르고 WARP가 Traffic and DNS로 복귀했는지 확인한 뒤 **종료**합니다. 복구 오류가 있으면 기존 앱에서 먼저 복구하세요.
2. MacBook CPU에 맞는 AppleSilicon 또는 Intel DMG를 받아 `MINER.app`을 Applications로 옮깁니다. 앱·지원 폴더·설치 식별자는 ALPHA와 호환되므로 기존 앱을 교체합니다.
3. 이번 빌드가 ad-hoc 서명인 경우 Apple 공증을 받은 앱이 아닙니다. macOS가 실행을 막으면 시스템 설정의 개인정보 보호 및 보안에서 해당 앱을 확인하세요. 서명 손상 경고는 정상적인 미공증 경고와 구분해야 합니다.
4. MINER 설정에서 '항상 허용'을 사용하면 버전이 바뀐 root helper 설치 때 한 번 관리자 인증이 필요할 수 있습니다.
5. 실제 경기가 끝난 상태라면 Riot/LoL 클라이언트를 열어 둔 채 MINER **시작**을 누릅니다. 앱은 클라이언트를 종료하거나 재실행하지 않습니다. 이미 열린 연결과 앱 내부 DNS 캐시는 자동 이전되지 않으므로 기존 요청의 즉시 복구는 보장하지 않습니다. `Riot 검사 PASS`는 고정 HTTPS 종단점 확인이며 로그인·영상·통계 기능 성공을 보증하지 않습니다.
6. 게임 중에도 MINER와 WARP Local Proxy를 유지합니다. Local Proxy는 MASQUE의 UDP 전송 설정과 별개입니다. 경기 경계에서 WARP를 켜고 끄는 시험은 하지 않습니다.

## 같은 연결로 10회 반복

우선 연습 모드를 사용하세요. 매 회 다음 순서를 기록합니다.

- 로그인 → 로비 → 게임 시작 → 게임 중 클릭 반응·핑 → 게임 종료 → 통계창 → 다음 로비.
- 통계창이 **30초 안에** 표시되는지 확인합니다. 30초 이상이면 `timeout_30s`로 기록하고 실제 시각과 무한 로딩/연결 오류/창 멈춤을 구분합니다.
- 각 회 사이에 MINER·WARP 모드를 바꾸거나 클라이언트를 재시작했다면 기록합니다. 재시작으로 회복한 회는 연속 성공으로 세지 않습니다.
- 같은 조건에서 브라우저·메신저도 확인합니다. 시험 때문에 새로 발생한 지연과 원래 네트워크 변동을 구분하세요.

같이 받은 진단 ZIP을 풀고 터미널에서 다음 명령을 사용합니다. `--active`를 넣지 않으면 외부 DNS/TLS 검사는 하지 않습니다. 로컬 SOCKS 인사·OS 상태 읽기는 수행합니다. 자동 업로드는 없습니다.

```bash
cd "진단 ZIP을 푼 폴더"
./MINER-Diagnostics --interactive --cycle 1
```

연결 전 / 연결 후 / 게임 중 / 통계창 / 중지 후를 선택합니다. 통계창 단계에서는 표시됨·30초 이상 로딩·오류를 선택합니다. 다음 회는 `--cycle 2`처럼 별도 파일로 기록합니다. 최초 원인 비교용으로만 `--active`를 추가할 수 있습니다. 능동 검사의 HEAD 요청은 실제 통계 요청과 구분되어 기록됩니다.

첨부 CSV의 빈 10개 행에 결과를 기록하세요. 계정·SSID·게임 서버 IP·인증 토큰·원문 네트워크 로그는 보내지 마세요. 진단 ZIP의 `report.json`을 확인한 뒤 공유하면 됩니다.

## 연결 수명과 복구 시험

실제 게임을 시작하기 전에 별도로 확인합니다.

| 동작 | 예상 동작 |
|---|---|
| 창의 닫기 버튼 | 연결 유지. 메뉴 막대 MINER → 열기로 복귀 |
| UI 강제 종료 | launchd 엔진 유지. 앱 재실행 후 기존 엔진 상태 확인 |
| 메뉴의 Stop 또는 앱의 중지 | 원래 DNS 복구 후 엔진 종료, WARP를 고정 정책인 Warp / Traffic and DNS로 연결 |
| Quit / Cmd+Q | 중지·복구 완료 후 종료 |
| 로그아웃/사용자 전환 | root helper가 엔진·DNS 정리. 사용자 WARP 복귀는 다음 로그인 후 명시적 중지로 확인 |
| 재부팅 | 엔진 자동 연결 안 함. 미완료 DNS 기록은 helper 복구 대상으로 유지 |
| 절전/네트워크 변경 | 재검사 후 상태 표시. 새 NIC의 DNS나 WARP 모드를 자동 덮어쓰지 않음 |

로그아웃 때 WARP까지 완전 복귀하는 동작, 다른 사용자 로그인, 24시간 유지, 8GB 메모리 환경 및 통계창 10회는 별도 실기 gate입니다. 이번 프리뷰만으로 통과를 선언하지 않습니다.

## 원복

STRATA에서 중지·복귀 완료 → Quit → 보관한 ALPHA 1.2.3 앱으로 교체합니다. 기존 지원 폴더와 DNS 복구 기록을 지우지 마세요. ALPHA가 helper 버전 불일치를 알리면 정지 상태에서 다시 승인해 설치합니다. 실제 ALPHA→STRATA→ALPHA 게임 복귀 경로는 미검증입니다. Homebrew cask와 정식 자동 업데이트 채널은 이번 프리뷰로 바뀌지 않습니다.

## 진단 도구와 앱 버전 확인

Diagnostics 2.0.1을 받는 것과 MINER 앱을 업데이트하는 것은 별개입니다. Mac용 앱은 Preview 4 DMG에서 설치합니다. 시스템 설치본과 실행 중인 복사본이 다를 수 있으므로, 앱을 교체한 뒤에는 기존 MINER를 종료하고 다음 명령으로 새 설치본을 여세요.

```bash
open -n "/Applications/MINER.app"
```

설정의 About에서 STRATA Preview 4를 확인한 다음, 실제 경기 중이 아닌 상태에서 MINER를 시작합니다. Riot/LoL 클라이언트는 열어 두어도 됩니다. 게임/통계 시험 전에 진단의 연결 후 샘플에서 SELECTIVE_COMPONENTS_OBSERVED가 기록되는지 확인하세요. 구성 요소 관측은 실제 로그인·통계 성공을 뜻하지 않습니다. 엔진이 관측되지 않거나 전체 WARP 모드라면 게임 도중 바꾸지 말고 게임 종료 후 시작 오류부터 확인합니다.

## 클라이언트를 열어 둔 시작 시험

로비를 연 상태에서 시작 전/연결 후 진단을 기록합니다. 시작 차단 오류가 사라지는지와 실제 로비·게임→통계창 성공 여부를 구분해 기록하세요. 기존 연결의 실패가 지속되면 오류 시점부터 먼저 기록합니다. 이 버전은 이미 열린 소켓을 강제로 이동시키거나 클라이언트의 private DNS 캐시를 삭제하지 않습니다. 실제 경기 프로세스가 실행 중이면 기존처럼 설정 변경 전에 차단됩니다.

## 친구 상태·매칭 알림 시험

이 빌드는 선택 Riot 도메인의 HTTPS/SVCB 실제 주소 힌트를 억제해 A/AAAA 가상 주소 경로를 사용하도록 보완합니다. 이 허점은 loopback DNS fixture로 재현·수정했으나, 사용자에게 발생한 친구 상태·수락창 문제가 이 레코드를 사용했다는 증거는 아직 없습니다.

진단 2.0.2의 같은 창에서 정상 로비는 2, 문제가 난 직후는 6을 선택하고 수락창 누락/온라인·오프라인 불일치를 구분하세요. 클라이언트가 멈춘 상태를 먼저 기록한 뒤 복구하세요. 실제 랭크 게임을 시험용으로 시작할 필요는 없습니다. 소켓의 ESTABLISHED나 포트 종류는 실제 채팅 로그인·매칭 알림 전달 성공의 증명이 아닙니다.
