# STRATA artwork and README release policy

- `docs/assets/miner-strata-readme-banner.png`: generated visual, development-preview hero.
- `docs/assets/miner-strata-system-banner.png`: second generated visual, schematic/roadmap motif; conceptual illustration, not a network-topology proof.
- Colors guided by current ALPHA README badges: neon green `#0EFB2E` family, midnight navy, ivory.
- README preview is `README_STRATA_PREVIEW.md` and **does not replace the stable `README.md`**. GitHub branch can preview it; do not publish stable/download badges for 2.0.0 until tested and released.
- Images originated with image generation for this project; original ALPHA binary image assets were not fetched or incorporated.
- Avoid claiming this illustration is a screenshot, a functioning connection, or evidence of measured performance.

- Added `docs/assets/miner-strata-release-preview-banner.png` as a successor-style concept to ALPHA release art, not a released product announcement.
- Preserve the two ORIGINAL ALPHA assets from the full Git checkout; see `ALPHA_ARTWORK_PRESERVATION_KO.md` and the package-root `ALPHA_AND_STRATA_ARTWORK_MANIFEST.json`.
- Exact ALPHA original PNG pixel dimensions and font face were not inspectable within this package. Codex must compare the original first; do not claim exact visual parity without confirmation.
