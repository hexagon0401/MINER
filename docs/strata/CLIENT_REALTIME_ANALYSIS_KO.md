# 친구 상태·매칭 수락창 문제 조사

## 관측과 미확인 사항

MINER 연결 후 클라이언트를 실행했는데도 친구 상태가 일치하지 않거나 매칭 수락창이 표시되지 않았다는 사용자 보고가 있습니다. 시작 전에 열려 있던 클라이언트만을 원인으로 단정할 수 없습니다. 해당 오류 시점의 실제 서버 요청·알림 수신·클라이언트 연결 자료는 아직 없습니다. 친구 상태와 매칭 알림이 반드시 같은 세션을 사용한다고 가정하지 않습니다.

현재 선택 규칙은 인식된 Riot 가상 주소의 TCP를 포트 제한 없이 WARP로 보냅니다. 포트나 Riot 도메인을 추측해 추가하는 패치는 하지 않았습니다. auth.riotgames.com의 HEAD 응답은 실제 친구 상태·파티·알림 전달의 성공 검사가 아닙니다.

## 재현한 DNS 허점과 Preview 4 변경

기존 규칙은 선택 Riot 도메인의 A/AAAA만 FakeIP로 처리하고 HTTPS(65)/SVCB(64)는 일반 DNS로 전달했습니다. 이 레코드의 실제 주소 힌트나 대체 대상이 사용되면 가상 주소 기반 선택 경로 밖으로 나갈 수 있습니다.

고정 sing-box 1.12.0에 loopback DNS upstream fixture를 연결해 수정 전 Riot HTTPS 응답의 실제 주소 힌트 전달을 재현했습니다. 사용자 패킷을 측정한 것이 아닙니다. Preview 4는 선택 도메인의 HTTPS/SVCB를 NODATA(NOERROR·응답 없음)로 처리해 기본 A/AAAA 조회 경로를 유지합니다. 이 레코드에 의존하는 앱 전체를 지원한다고 보장하지 않습니다.

패킷 기반 회귀 검사는 Mac/Windows 프로필 각각에서 다음을 확인합니다.

- 선택 Riot 도메인의 두 레코드가 실제 IP 힌트 없이 빈 NOERROR로 반환되고 일반 upstream에 전달되지 않음.
- 일반 사이트와 비슷한 이름의 비선택 도메인 레코드는 원래 upstream 응답을 유지함.
- 선택 도메인의 IPv4·IPv6 주소 조회는 계속 가상 주소를 반환함.
- 시험에서 OS DNS·기본 경로·TUN·WARP는 변경하지 않음.

이것은 재현 가능한 선택 경로 허점의 수정입니다. **사용자의 친구 상태·수락창 누락 원인이 이 레코드 사용이었는지, 실제 증상이 해결됐는지는 미확인**입니다. 이미 열린 소켓이나 앱 내부 캐시를 강제로 변경하지 않습니다. 클라이언트 종료 차단을 다시 추가하지 않았습니다.

## Diagnostics 2.0.2

클라이언트 TCP 메타데이터를 역할·포트 종류·가상/실제/loopback 주소 범주·TCP 상태로 집계합니다. 원래 주소·PID·경로·인자·계정·토큰은 내보내지 않습니다. lockfile·로컬 인증 API·패킷을 읽지 않습니다. Mac은 현재 사용자, Windows는 현재 세션의 지정 프로세스만 출력 대상으로 삼습니다.

5223 등의 포트 이름은 후보 분류이지 실제 서비스 식별이 아닙니다. ESTABLISHED도 채팅 인증이나 알림 수신 성공이 아닙니다. 조회 실패·빈 관측·이미 닫혀 사라진 연결을 구분해야 하며, 다른 VPN의 실제 경로도 포트 정보만으로 판정하지 않습니다.

같은 진단 창에서 정상 로비 2, 문제 직후 6을 기록하고 수락창 누락/온라인 상태 불일치/파티 오류를 선택합니다. 재시작 전에 기록하면 연결 대기·종료·실제 주소 사용 여부를 비교할 수 있습니다. 시험을 위해 실제 랭크 게임을 시작할 필요는 없습니다. 최신 보고서를 확인해야 다음 변경을 특정 서비스나 전송 오류에 한정할 수 있습니다.

## 검증 기록의 한계와 CI 보완

Diagnostics 2.0.2의 세 플랫폼 패키징·읽기 전용 실행 및 두 Mac 소켓 fixture는 통과했습니다. 이후 Preview 4의 엄격한 Windows 회귀에서 Mac bundle 경로 fixture의 구분자 가정이 드러났습니다. 기존 진단 워크플로는 Windows에서 중간 테스트 명령의 실패를 마지막 명령이 가릴 수 있었습니다. 실제 소켓 집계 코드의 Windows 실패를 숨기는 대신 경로 비교를 as_posix로 고치고 각 명령의 종료 코드를 검사하도록 보완했습니다. 실패한 앱 CI에서는 배포하지 않았습니다.

최종 앱 CI·소스·파일 해시는 PREVIEW4_VALIDATION.json에 기록합니다. Windows 검증은 Windows Server CI이며 실제 Windows 11/게임 성공 검사가 아닙니다. main·기존 ALPHA·Homebrew·이전 릴리스를 덮어쓰지 않습니다.
