**MINER DELTA — 5.0.0-delta.1** macOS 사전 릴리스입니다.

- 앱 파일·실행 파일·Dock 이름을 **MINER**로 통일했습니다. 기존 앱을 중지·종료한 뒤 `MINER.app`을 Applications로 드래그하세요. 기존 설정·로그·서비스 식별자는 유지합니다.
- Delta v2.1 최종 명세에 맞춰 제목 표시줄 표면을 숨기고 네이티브 창 버튼·드래그·크기 조절을 유지했습니다. 기본 560×610pt, 최소 520×570pt의 전체 창 동굴과 시스템 소재를 사용합니다.
- 원본 캐릭터·학교·아이콘·문구·실제 다섯 단계 막대와 기존 네트워크 엔진을 보존했습니다.
- 세로 시작·중지 버튼에 일회성 초록·빨강 파동을 넣었습니다. 전체 엔진 성공 때만 천장 빛·중앙 체크·배경 블러를 재생하고 복원합니다. WARP-only는 구분하며 중지·오류 시 연출을 취소합니다.
- ⌘, 한/영 설정, 진단·로그·도움말·제거와 동작/투명도 줄이기를 유지합니다.
- 이번 Delta는 Apple Silicon용 DMG를 우선 제공하며 UI fixture, 실제 엔진 설정, DMG 배경·아이콘 위치, 마운트/복사 후 서명을 검사합니다. DMG·SHA-256·검증 JSON을 함께 제공합니다.

DMG는 제공된 MINER 동굴 배경의 왼쪽 앱을 오른쪽 Applications로 옮기는 구성입니다. Python·sing-box가 포함되며 개인용 Cloudflare WARP는 별도 설치가 필요합니다.

Apple 인증서가 설정되지 않은 빌드는 **ad-hoc이며 Apple 공증이 없습니다**. 실제 서명 모드는 DMG의 `.verification.json`에서 확인하세요. 인증서·공증 설정 시 실패를 ad-hoc으로 대체하지 않습니다.

학교에서의 접속 성공, macOS 27.1.1의 실제 라우팅·복구, LoL 영상·게임 RTT/FPS는 사용자 환경에서 확인해야 합니다. 이번 변경은 UI·앱 이름·패키징에 한정하며 네트워크 동작 변경은 없습니다.
