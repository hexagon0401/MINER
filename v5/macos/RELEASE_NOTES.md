**MINER BETA 2 — 5.0.0-beta.2 개발본**

- 설정의 학교 현황, 지역·학교명·학교급·깃발 검색을 추가했습니다.
- 내 기기의 즉시 성공 기록과 운영자 승인이 필요한 전국 공유 기록을 구분합니다.
- 읽기 전용 엔진/WARP 진단, 실제 클라이언트 사용 자기 확인, 선택적 게임·영상·복귀 결과, 서명 제보 JSON 내보내기를 지원합니다.
- 누적 성공은 90일 이후에도 유지하고 오래된 기록·최근 실패를 별도 표시합니다.
- 공유 서버는 개방하지 않았습니다. 로컬 Workers/D1 테스트와 운영자 승인·반려·철회 CLI만 준비했습니다.
- 전체 공식 학교 명부가 필요합니다. 미완료·샘플 자료로 전국 수치를 만들거나 배포용 DMG를 게시하지 않습니다.
- 기존 베타 아이콘·개발자 소개·Delta 화면·다섯 단계 진행과 네트워크 엔진을 유지했습니다.

설치 가능한 최신 버전은 베타 1 프리릴리스의 Apple Silicon DMG입니다. 베타 2 전체 명부·서명·공개 전환의 남은 항목은 `v5/docs/BETA2_HANDOFF.md`에 있습니다.
