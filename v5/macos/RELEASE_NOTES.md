**MINER BETA — 5.0.0-beta.1** macOS 사전 릴리스입니다.

- 제공된 **MINER-BETA.icon**의 광부·BETA 워드마크·배치를 앱 아이콘에 적용했습니다. 원본 Icon Composer 프로젝트도 저장소에 보존합니다.
- ⌘, 또는 도구 → 설정에 **개발자 소개 / About** 섹션을 추가했습니다. **Punkthats*it · @hexagon0401**의 GitHub 프로필 이미지와 프로필 링크를 표시합니다.
- 프로필 이미지는 빌드 시 공개 GitHub 프로필에서 가져와 앱에 포함하므로, 설정을 열 때 네트워크 요청을 하지 않습니다.
- 기존 Delta v2.1 화면, 학교·캐릭터·실제 다섯 단계 진행, WARP/분리 라우팅 엔진과 설정·로그를 유지합니다.
- 앱 이름과 설치 경로는 **MINER.app**입니다. 기존 앱을 중지·종료한 뒤 Applications로 옮기세요.

Apple Silicon DMG는 macOS 네이티브 빌드·UI 검사·DMG 복사 후 서명 검증에 성공한 경우에만 첨부됩니다. 서버 미배정 또는 검사 실패 시 소스 프리릴리스만 제공되며, DMG가 첨부되지 않았으면 설치 파일 배포가 완료된 상태가 아닙니다.

DMG가 제공되면 기존 동굴 배경의 왼쪽 앱을 오른쪽 Applications로 옮기는 방식으로 설치합니다. SHA-256과 검증 JSON을 함께 제공합니다. 개인용 Cloudflare WARP는 별도로 설치·등록해야 합니다.

인증서가 설정되지 않은 빌드는 **ad-hoc 서명이며 Apple 공증이 없습니다**. 실제 상태는 DMG의 `.verification.json`에서 확인하세요. 학교 접속·LoL 영상·게임 핑·실제 WARP 복귀는 사용자 환경에서 확인해야 합니다.
