MINER ALPHA v1.2.1 — macOS

설치와 첫 연결
1. DMG에서 MINER.app을 Applications로 드래그해 설치하거나 기존 앱을 교체하세요.
2. 개인용 Cloudflare WARP를 별도로 설치하고 최초 등록을 마쳐 주세요.
3. 게임과 Riot/LoL 클라이언트를 종료한 상태에서 MINER의 시작을 누르세요.
   WARP CLI가 Local Proxy 127.0.0.1:40000을 준비하고 SOCKS5·TLS·warp=on을 확인합니다.
   최초 전체 터널 → 프록시 전환은 게임 밖에서 진행하세요.
4. 관리자 승인 재사용을 켜면 도우미 설치·버전 업데이트 때 한 번 승인합니다.
   해제하면 매 연결을 인증합니다. 복구 도우미는 어느 설정에서도 설치됩니다.
   비밀번호를 저장하지 않으며 부팅 후 게임 엔진이나 WARP를 자동 연결하지 않습니다.
5. 연결 완료 후 Riot/LoL 클라이언트를 실행하세요. 로그인·게임·통계창까지
   MINER와 WARP를 계속 켜 두세요. 게임 중 WARP를 직접 전환하지 마세요.

연결 구조
- 지정된 Riot 도메인의 TCP만 가상 주소를 통해 WARP Local Proxy로 전달합니다.
- 일반 브라우저·다른 앱·실제 게임 서버 IP는 원래 OS 경로를 유지합니다.
- 일반 DNS는 원래 연결의 DNS 서버로 전달하며 변경 전 설정을 기록합니다.
- WARP 장애 시 Riot 통신을 직접 연결이나 전체 터널로 자동 전환하지 않습니다.
- 프록시 모드에서 끊어진 WARP에는 connect만 재시도하고 건강한 연결은 유지합니다.

중지와 복구
- 사용 후 중지를 누르면 원래 DNS 설정을 복구한 뒤 엔진을 종료하고,
  WARP를 UDP Traffic and DNS로 복귀시켜 실제 CLI 결과를 확인합니다.
- 게임 종료 후 통계창에 들어갈 때는 중지할 필요가 없습니다.
- 비정상 엔진 종료 시 복구 도우미가 DNS를 복구합니다. WARP 전체 모드로
  자동 전환하지 않습니다. 앱을 다시 열어 중지로 복구 결과를 확인하세요.
- 복구 실패 시 오류와 기록을 유지합니다. 다른 VPN이나 네트워크가 바뀌었다면
  연결을 중지하고 다시 시작하세요. 게임 중 업데이트하지 마세요.

설정과 업데이트
⌘, 또는 설정 버튼에서 한국어/English, 관리자 승인 재사용, 자동 업데이트
확인, 개발자 소개를 설정합니다. 새 버전은 실행 후 및 6시간 간격으로 확인해
앱에서 알립니다. 연결을 중지한 뒤 업데이트 설치를 진행하세요.
Homebrew 설치는 Terminal에서 brew update / brew upgrade --cask miner를 실행합니다.
v1.2.1부터 이후 DMG 업데이트는 검증 후 앱 종료·교체·재실행하고 새 창 시작 확인 후 이전 앱과 설치 캐시를 정리합니다.
기존 앱을 먼저 제거하지 않아도 됩니다. v1.1.1 사용자는 한 번 수동 확인이 필요합니다.

제거
앱의 제거 기능은 중지·DNS 복구 후 관리 중인 도우미·지원 파일·설정·로그를
삭제하고 앱을 휴지통으로 옮깁니다. WARP와 이전 v1~v4는 보존합니다.
필요한 로그는 제거 전에 복사하세요. 업데이트에는 제거 기능을 사용하지 마세요.

배포 서명
인증서가 설정되지 않은 배포는 ad-hoc 서명이며 Apple Developer ID 서명·공증은 되어 있지 않습니다.
macOS가 실행을 막으면 공식 릴리스 출처를 확인한 후 시스템 설정 → 개인정보 보호 및 보안의
해당 앱 확인 없이 열기 절차를 사용하세요. Gatekeeper를 전역으로 끄지 마세요.

설치 위치
앱: /Applications/MINER.app
사용자 설정: ~/Library/Application Support/SchoolNet v5 Alpha
관리되는 런타임·로그·DNS 복구 기록: /Library/Application Support/SchoolNet v5 Alpha
엔진 작업: org.schoolnet.v5.alpha
복구 도우미: org.schoolnet.v5.alpha.helper (부팅 후 대기하되 자동 연결하지 않음)

제한과 검증
- macOS Apple Silicon과 Intel에 맞는 DMG를 선택하세요. Windows는 별도 Setup.exe입니다.
- 일반 앱의 실제 IP는 TUN을 통과하지 않지만 CPU·핑·FPS 무영향을 보장하지 않습니다.
- 지정된 Riot 가상 주소의 UDP는 거부합니다. 음성·QUIC 등은 별도 확인이 필요합니다.
- 다른 VPN·브라우저 자체 DoH·연결 변경·학교별 정책에 따라 결과가 달라집니다.
- 실제 학교망·개인용 WARP·LoL·영상·게임 지연은 실기 테스트가 필요합니다.
- UI 검증 캡처는 주입된 상태이며 실제 게임 접속 성공 화면이 아닙니다.
- 베타 2 학교 현황·제보 기능은 보관 소스이며 이 정식 UI에 포함되지 않습니다.
