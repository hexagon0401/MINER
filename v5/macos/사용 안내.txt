SchoolNet v5 Alpha — macOS 테스트 배포

1. DMG를 열고 SchoolNet v5 Alpha.app을 Applications로 드래그하세요.
2. Applications에서 앱을 실행하세요. Python·sing-box는 앱 안에 포함되어 있습니다.
3. 개인용 Cloudflare WARP 앱은 별도로 설치되어 있어야 합니다.
   WARP Preferences → Advanced → Configure Proxy에서 포트를 40000으로 설정하고
   Local proxy 모드로 연결하세요. 기존 전체 WARP 터널과 동시에 사용하지 마세요.
4. SchoolNet의 '사전 점검'을 누른 뒤 '시작'을 누르세요.
   macOS 관리자 인증은 임시 네트워크 경로 설정을 위한 것입니다.
   앱은 비밀번호를 저장하거나 직접 입력받지 않습니다.
5. 클라이언트 TCP는 WARP, 게임 데이터는 직접 연결하는 구성입니다.
   '로그 열기'에서 클라이언트 outbound/socks[warp], 게임 outbound/direct[direct]를 확인하세요.
   실제 학교 접속 성공·게임 핑·macOS 27.1.1 호환성은 사용자 테스트가 필요합니다.
6. 사용 후 '중지'를 누르세요. 앱 종료 시에도 실행 중이면 중지를 안내합니다.
   앱을 강제 종료한 경우 다시 열어 '중지'를 눌러주세요.

제거
- 앱의 '제거' 버튼을 누르면 실행을 중지하고 v5의 설치 상태·설정·로그를 제거한 뒤
  앱을 휴지통으로 옮깁니다. WARP와 v1~v4, 다른 네트워크 설정은 제거하지 않습니다.
- 앱만 휴지통으로 옮기면 실행 중인 네트워크 프로세스/지원 파일이 남을 수 있으므로
  먼저 앱의 '제거' 기능을 사용하세요.
- 제거 전에 테스트 로그가 필요하면 '로그 열기'로 별도 복사하세요.

배포 서명
이 alpha는 ad-hoc 서명이며 Apple Developer ID 서명·공증은 되어 있지 않습니다.
macOS가 실행을 막으면 파일 출처를 확인한 후 시스템 설정 → 개인정보 보호 및 보안의
해당 앱 '확인 없이 열기' 절차를 사용하세요. Gatekeeper를 전역으로 끄지 마세요.

설치 위치
앱: /Applications/SchoolNet v5 Alpha.app
사용자 설정: ~/Library/Application Support/SchoolNet v5 Alpha
실행 지원 파일·로그: /Library/Application Support/SchoolNet v5 Alpha
launchd 작업: org.schoolnet.v5.alpha (로그인/부팅 자동 시작 항목은 설치하지 않음)

제한
- 클라이언트 UDP는 지원을 가정하지 않고 거부합니다. 음성 등 부가 기능은 실패할 수 있습니다.
- 로컬 TUN 처리 비용은 남습니다. 무지연·FPS 무영향은 보장하지 않습니다.
- DNS는 WARP 경유 DoH를 사용합니다. WARP가 끊기면 새 DNS 조회도 실패할 수 있습니다.
- Apple Silicon과 Intel DMG를 구분해 다운로드하세요.
- Windows는 CLI 설정 생성만 제공하며 이 DMG는 macOS용입니다.
