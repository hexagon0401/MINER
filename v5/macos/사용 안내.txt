MINER BETA — macOS 테스트 배포

1. DMG를 열고 MINER.app을 Applications로 드래그하세요.
2. Applications에서 앱을 실행하세요. Python·sing-box는 앱 안에 포함되어 있습니다.
3. 개인용 Cloudflare WARP 앱은 별도로 설치·등록되어 있어야 합니다.
   'WARP 자동 연결' 또는 '시작'을 누르면 warp-cli로 Local Proxy(포트 40000)를
   설정하고 TLS와 warp=on을 확인합니다. 최신 GUI에 Configure Proxy 메뉴가 없어도 됩니다.
   최초 전체 터널에서 프록시로 전환할 때는 게임을 종료한 상태에서 진행하세요.
4. MINER의 '시작'을 누르세요. 이미 정상 프록시이면 재연결하지 않습니다.
   macOS 관리자 인증은 임시 네트워크 경로 설정을 위한 것입니다.
   앱은 비밀번호를 저장하거나 직접 입력받지 않습니다.
5. 클라이언트 TCP는 WARP, 게임 데이터는 직접 연결하는 구성입니다.
   '로그 열기'에서 클라이언트 outbound/socks[warp], 게임 outbound/direct[direct]를 확인하세요.
   실제 학교 접속 성공·게임 핑·macOS 27.1.1 호환성은 사용자 테스트가 필요합니다.
6. 사용 후 '중지'를 누르세요. 엔진 중지 후 WARP를 UDP Traffic and DNS로 복귀합니다. 앱 종료 시에도 실행 중이면 중지를 안내합니다.
   앱을 강제 종료한 경우 다시 열어 '중지'를 눌러주세요.
   앱 종료도 엔진 중지와 WARP UDP 복귀를 확인합니다. 복귀 실패 시 오류를 표시합니다.
   프록시 연결 실패 시 일반 네트워크로 자동 재시도하지 않습니다.
7. alpha.4는 Riot/League의 웹 Helper 경로도 터널 대상으로 포함합니다.
   영상이 계속 비면 로그에서 Helper의 실제 경로와 warp 매칭을 확인하세요.
   게임 실행 파일의 TCP/UDP는 직접 경로를 우선합니다.

제거
- 앱의 '제거' 버튼을 누르면 실행을 중지하고 v5의 설치 상태·설정·로그를 제거한 뒤
  앱을 휴지통으로 옮깁니다. WARP와 v1~v4, 다른 네트워크 설정은 제거하지 않습니다.
- 앱만 휴지통으로 옮기면 실행 중인 네트워크 프로세스/지원 파일이 남을 수 있으므로
  먼저 앱의 '제거' 기능을 사용하세요.
- 제거 전에 테스트 로그가 필요하면 '로그 열기'로 별도 복사하세요.

배포 서명
인증서가 설정되지 않은 배포는 ad-hoc 서명이며 Apple Developer ID 서명·공증은 되어 있지 않습니다.
macOS가 실행을 막으면 파일 출처를 확인한 후 시스템 설정 → 개인정보 보호 및 보안의
해당 앱 '확인 없이 열기' 절차를 사용하세요. Gatekeeper를 전역으로 끄지 마세요.

설치 위치
앱: /Applications/MINER.app
사용자 설정: ~/Library/Application Support/SchoolNet v5 Alpha
실행 지원 파일·로그: /Library/Application Support/SchoolNet v5 Alpha
launchd 작업: org.schoolnet.v5.alpha (로그인/부팅 자동 시작 항목은 설치하지 않음)

제한
- 클라이언트 UDP는 지원을 가정하지 않고 거부합니다. 음성 등 부가 기능은 실패할 수 있습니다.
- 로컬 TUN 처리 비용은 남습니다. 무지연·FPS 무영향은 보장하지 않습니다.
- DNS는 WARP 경유 DoH를 사용합니다. WARP가 끊기면 새 DNS 조회도 실패할 수 있습니다.
- Apple Silicon과 Intel DMG를 구분해 다운로드하세요.
- Windows는 CLI 설정 생성만 제공하며 이 DMG는 macOS용입니다.

MINER 디자인 UI: 시작/중지와 실제 다섯 단계 상태를 표시합니다.
⌘, 또는 도구 → 설정에서 한국어/English를 바꿀 수 있습니다.
상태·로그는 별도 진단 화면에서 확인합니다.

Delta v2.1: 네이티브 창 버튼을 유지한 전체 동굴 화면입니다. 성공 연출은 전체 엔진 실행 때만 나타납니다.
기존 SchoolNet 앱을 먼저 중지·종료하고 새 MINER 앱을 설치하세요. 기존 설정은 유지합니다.

BETA 아이콘 적용. 설정의 개발자 소개에서 Punkthats*it · @hexagon0401의 프로필을 확인할 수 있습니다.
프로필 이미지는 앱에 포함되어 있으며 GitHub 링크를 누를 때만 브라우저를 엽니다.
