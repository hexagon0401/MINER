# MINER Local Diagnostics v1.0.1

통계창 무한 로딩을 구분하기 위한 독립 진단 도구입니다. 정식 MINER 1.2.2·Homebrew는 변경하지 않습니다.

- 실행 시 고정 Cloudflare/Riot/LoL DNS·HTTPS 요청 허용을 질문합니다. `y` 또는 `--active`일 때만 검사하며 ON/OFF를 명확히 표시합니다. 네트워크 설정은 변경하지 않습니다.
- 과거 로그와 샘플 이후의 새 오류를 구분합니다. 로그 회전·잘림을 감지합니다. SOCKS 연결 거부·EOF·TLS·DNS 등 허용된 오류 유형만 집계하고 원문·IP·계정·토큰·전체 호스트 이름은 내보내지 않습니다.
- 통계창이 멈춘 상태에서 `4`를 기록한 뒤 바탕화면 ZIP을 전달하세요. WARP/클라이언트를 재시작하기 전에 수집하는 것이 중요합니다. 이미 실패가 재현됐다면 새 게임을 일부러 반복할 필요는 없습니다.

Mac은 ZIP의 `시작.command`, Windows는 EXE를 실행합니다. Python·관리자 권한이 필요하지 않습니다. Mac ad-hoc/공증 없음, Windows 미서명입니다. 자동 업로드하지 않으며 ZIP을 확인한 후 직접 전달합니다. 네이티브 검사 통과는 실제 학교망·Riot 통계 API·Vanguard 호환성 검증이 아닙니다. 상세 항목과 한계는 동봉 README_KO.md를 확인하세요.
