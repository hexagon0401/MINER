## MINER ALPHA v1.1.1

- 일반 웹의 DNS를 시스템 DNS로 분리하고 전역 strict route를 해제했습니다. Riot 클라이언트와 Riot 도메인 DNS만 WARP를 사용하며, Riot 프록시 실패 시 직접 경로로 전환하지 않습니다.
- macOS 설정에 관리자 승인 재사용 도우미를 추가했습니다. 최초 설치·도우미 업데이트 시 한 번 승인하며 비밀번호를 저장하지 않습니다. 도우미가 재부팅 후 대기하더라도 엔진은 자동 시작하지 않습니다. 앱 설정의 제거 기능으로 도우미도 삭제됩니다.
- macOS 5단계 상태 문구를 일반적인 안내로 변경하고 LoL 패러디 대사는 보존했습니다.
- 양쪽 설정에 업데이트 확인·설치 버튼을 추가했습니다. 정식 릴리스만 확인하고 SHA-256 검증 뒤 설치를 진행합니다. Homebrew 설치는 Terminal에서 Homebrew로, 직접 설치한 Mac 앱은 검증한 DMG를 열어 드래그 교체하며, Windows는 앱 종료 뒤 설치 프로그램을 실행합니다.
- Windows에서 사용하지 않는 Qt 기능과 Mac 전용 이미지를 제외하고 압축을 강화했습니다. 실제 크기와 80MB 목표 달성 여부는 Windows 검증 JSON에 기록합니다. 설정 저장 중 남은 임시 파일이 다음 저장을 막는 문제도 수정했습니다.

WARP가 꺼진 조건의 로컬 DNS·TLS HTTPS 회귀 검사와 Riot DNS의 직접 경로 차단, 네이티브 Mac UI·서명·DMG 복사 설치·도우미 피어 인증, Windows UI·TUN·설치·재설치·제거를 검사한 뒤 게시합니다. 실제 Arc·학교망·LoL·Vanguard의 실기 검증은 별도이며, 연결 전환 중 이미 열려 있던 브라우저 연결은 다시 시도해야 할 수 있습니다. 서명·공증 상태와 검사 범위는 각 설치 파일의 검증 JSON을 확인하세요.
