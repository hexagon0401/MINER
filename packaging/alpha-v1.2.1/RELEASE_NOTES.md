# MINER ALPHA v1.2.1

설정의 **업데이트 확인 / Check for Updates**와 실행 중 자동 확인·안내를 유지하면서 설치·정리를 개선했습니다. 네트워크 엔진과 v1.2.0의 선택 라우팅은 유지합니다.

- 앱 실행 후 및 6시간마다 확인해 앱 안에 안내합니다. Mac은 Dock 배지, Windows는 새 버전 최초 발견 시 작업 표시줄 점멸도 사용합니다. 앱 종료 상태의 푸시는 아닙니다.
- **Mac 직접 설치:** 검증된 DMG를 내려받고 별도 작업자가 앱 종료 후 새 앱을 준비합니다. 앱 식별자·버전·코드 서명 무결성을 검사하고 기존 앱을 보관한 뒤 교체·재실행합니다. 새 창 시작 확인 후 이전 앱과 설치 캐시를 정리합니다. 시작 실패 시 백업을 보존하거나 이전 앱을 복구합니다. Applications에 쓰기 권한이 없으면 기존 앱을 보존하고 오류를 표시합니다.
- **Windows:** 앱 종료 후 설치 파일의 SHA-256을 다시 검사하고 같은 설치 위치에 설치·재실행합니다. 기존 런타임을 임시 보관한 뒤 새 런타임으로 교체해 삭제된 DLL 등이 누적되지 않게 합니다. 설치 실패 시 복구하고 성공하면 백업을 제거합니다.
- **캐시:** 앱이 시작되면 MINER 전용 Updates 폴더에서 현재 버전 이하의 MINER DMG·EXE·임시 다운로드만 정리합니다. 미래 버전 설치 파일, 개인 파일, 설정·로그·WARP는 삭제하지 않습니다. 잠긴 파일은 다음 실행에 다시 정리합니다. Homebrew 설치는 upgrade 후 MINER cleanup을 실행합니다.

## 기존 사용자

기존 MINER를 먼저 제거하지 마세요. 연결을 중지한 뒤 설정 → 업데이트 확인 → 업데이트 설치를 사용합니다. v1.2.0의 Mac 직접 설치는 기존 코드 때문에 이번 한 번 DMG에서 앱을 교체해야 하며, **v1.2.1부터 이후 버전 설치에 새 자동 교체 기능을 사용**합니다. Windows도 이번 최초 전환은 기존 설치 화면을 거칠 수 있습니다. GitHub에 직접 방문해 다운로드할 필요는 없습니다. Homebrew는 `brew update`와 `brew upgrade --cask miner`로 업데이트합니다.

## 검증

공통 회귀 검사, macOS Apple Silicon·Intel의 패키징된 업데이트 작업자에 의한 실제 앱 교체·새 창 시작·이전 리소스/캐시 제거, Windows Server 2025에서 공개 v1.2.0 위 덮어쓰기·실패 복구·실제 설치/재실행·캐시 정리를 필수로 검사합니다. 기존 DNS/선택 경로·UI 검증도 유지합니다. 플랫폼별 JSON과 SHA-256을 첨부합니다.

실제 학교망·WARP·LoL·Vanguard·Windows 11 플레이는 별도 검증입니다. macOS ad-hoc 서명/공증 상태와 Windows Authenticode 상태는 검증 JSON을 확인하세요. 자동 업데이트는 사용자 설치 선택 후 진행하며 임의로 게임 중 설치하지 않습니다.
