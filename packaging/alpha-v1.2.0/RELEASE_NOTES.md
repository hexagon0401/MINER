# MINER ALPHA v1.2.0

게임 시작·종료 때 WARP를 수동으로 전환하던 불편함과 일반 앱까지 영향을 받던 경로를 개선했습니다. ALPHA는 제품 세대의 코드명입니다.

- **Riot 대상만 선택 경로:** 전체 기본 경로를 가상 어댑터에 넣던 구성을 제거했습니다. 지정된 Riot 도메인에만 가상 주소를 제공하고 TCP를 WARP Local Proxy로 보냅니다. 일반 브라우저·카카오톡·실제 게임 서버 IP는 OS의 원래 경로를 유지합니다.
- **연결 유지:** 로그인부터 인게임·종료 후 통계창까지 MINER와 WARP를 켜 두세요. 게임 단계에 따라 WARP를 끄거나 전체 터널로 바꾸지 않습니다. 건강한 연결을 재설정하지 않고, 끊어진 Local Proxy에는 connect만 재시도합니다.
- **DNS 복구:** 원래 연결의 DNS를 사용하고 자동/DHCP·수동 설정을 구분해 복구합니다. 변경 전에 복구 기록을 남기며, macOS 복구 도우미·Windows 별도 감시 프로세스가 비정상 종료 후 복구합니다. 일반 인터넷의 DNS를 WARP에 의존시키지 않습니다. 브라우저의 별도 보안 DNS/DoH는 OS DNS 경로를 사용하지 않습니다.
- **부하 감소:** 일반 앱과 실제 게임 서버 IP의 패킷은 MINER 엔진을 통과하지 않습니다. 연결별 정보 로그를 줄이고 DNS 전달 작업 수를 제한했습니다.
- **업데이트 알림:** 새 버전부터 실행 후 및 6시간 간격으로 확인해 앱에 안내합니다. 설정에서 끌 수 있습니다. 다운로드는 HTTPS와 SHA-256으로 검증합니다.

## 기존 사용자 업데이트

MINER에서 중지 → WARP 복귀 확인 → 설정의 업데이트 확인 → 설치. **기존 앱을 먼저 삭제할 필요가 없습니다.** Windows는 같은 위치에 설치하고 사용자 설정·로그를 보존합니다. Mac DMG는 응용 프로그램 폴더의 앱을 교체합니다. 도우미 버전이 바뀌므로 첫 연결에서 관리자 승인을 한 번 요청할 수 있습니다.

Homebrew:

```bash
brew update
brew upgrade --cask miner
```

v1.1.1에는 자동 확인 기능이 없어 이미 설치된 모든 사용자에게 소급 알림을 보낼 수 없습니다. 한 번 수동으로 업데이트한 뒤부터 새 자동 안내를 사용할 수 있습니다.

## 검증 범위

배포는 Apple Silicon·Intel macOS와 Windows Server 2025에서의 필수 자동 검증이 모두 통과해야 진행됩니다. 실제 선택 경로·원래 OS DNS와 HTTPS·동일 클라이언트 TCP 유지·DNS 복구·엔진 강제 종료 복구, 설치된 UI·DMG 서명 무결성·Windows 이전 정식 v1.1.1 위 덮어쓰기 업그레이드를 확인합니다. 네트워크 시험의 SOCKS 서버는 로컬 검증용이며 실제 WARP가 아닙니다. 플랫폼별 검증 JSON과 SHA-256을 첨부합니다.

**실제 학교망·개인용 WARP·LoL·Vanguard·Windows 11 게임 플레이는 원격 자동 시험으로 검증하지 않았습니다.** 이번 개선이 모든 Wi-Fi 손실·게임 지연을 해결한다고 주장하지 않습니다. 원래 DNS 서버/연결이 바뀌거나 다른 VPN이 동시에 기본 경로를 소유하면 중지 후 재연결해야 합니다. 지정 범위 밖의 클라이언트 서비스는 별도 확인이 필요합니다.

macOS는 설정된 Developer ID가 있으면 서명·공증 필수 검증, 미설정이면 ad-hoc 서명을 사용합니다. Windows는 Authenticode 미서명입니다. macOS와 Windows의 기존 UI와 정식 기본 아이콘을 유지합니다.
