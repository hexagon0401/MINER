# MINER STRATA 2.0.0 Preview 4 — 클라이언트 DNS 선택 경로 보완

선택 Riot 도메인의 A/AAAA는 가상 주소로 처리하지만 HTTPS/SVCB 레코드의 실제 IP 힌트는 일반 DNS에서 전달되던 허점을 재현하고 수정했습니다. 해당 레코드에는 NODATA(NOERROR·답변 없음)로 응답해 A/AAAA 조회 경로를 유지합니다. 일반 사이트의 HTTPS/SVCB 응답, 게임 실제 IP 직접 경로와 Stop 복구는 유지합니다.

**이 허점이 실제 친구 상태·수락창 누락의 원인인지는 미확인입니다.** 현재 자료로 해당 기능이 정상화됐다고 주장하지 않습니다. 레코드를 사용하지 않는 클라이언트 연결이나 이미 열린 소켓·앱 캐시는 이 변경으로 이동하지 않습니다.

- 실행 중인 LoL 클라이언트로 시작할 수 있는 Preview 3 동작을 유지합니다. 클라이언트 강제 종료·재실행·자동 수락은 없습니다.
- 진단 2.0.2를 함께 제공합니다. 클라이언트의 TCP 상태를 주소·계정·토큰 없이 집계하고 수락창 누락/친구 상태 불일치를 구분합니다. TCP ESTABLISHED는 실제 로그인·알림 성공을 증명하지 않습니다.
- 실제 sing-box 1.12.0에 loopback DNS fixture를 연결해 Riot의 실제 주소 힌트 차단, 일반 사이트 레코드 유지, A/AAAA 가상 주소 유지를 검증합니다. WARP·OS DNS·기본 경로를 바꾸지 않는 시험입니다.

macOS Apple Silicon/Intel 전용 수정 프리릴리스입니다. 공통 코드는 Windows 네이티브 DNS fixture 검사도 거치지만 이번에 Windows EXE를 새로 배포하지는 않습니다. main·ALPHA·Homebrew·기존 배포 파일은 보존합니다. 실제 학교망·LoL 로비/게임/통계·친구 상태·수락창은 미검증입니다.

## 설치 및 다음 시험

실제 경기가 끝난 상태에서 MINER만 정상 중지·종료하고 `/Applications/MINER.app`을 교체합니다. 새 앱의 About에서 Preview 4를 확인하세요. Riot/LoL 클라이언트를 매번 닫으라는 차단은 없습니다. Developer ID가 설정되지 않았다면 ad-hoc 서명·미공증입니다.

동봉한 진단 2.0.2의 같은 창에서 정상 로비 2(연결 후), 문제가 난 직후 6(오류)을 기록하고 증상을 선택하세요. 실제 랭크 게임을 시험용으로 시작할 필요는 없습니다. 클라이언트나 WARP를 재시작하기 전에 기록하면 실제 주소 경로 이탈·연결 대기/종료 상태를 구분하는 데 도움이 됩니다. 보고서를 검토한 뒤 직접 공유하세요. 자동 업로드는 없습니다.
