# MINER STRATA 2.0.0 Preview 7 — macOS Riot DNS 선택과 OS 경로 검사

활성 인터페이스에 MINER DNS가 설정돼 있어도 OS의 고정 Riot 주소 조회가 실제 주소를 반환하는 경우를 별도 공백으로 다룹니다. macOS에서는 기존 DNS 설정 방식에 더해 지정 Riot 도메인의 `/etc/resolver/` 보조 설정을 소유권 기록과 함께 설치합니다. 이미 있는 해당 도메인의 설정은 덮어쓰지 않습니다.

- 임시 DNS 복구 기록을 먼저 저장하고 파일을 설치합니다. 기존 활성 인터페이스의 DNS 변경·복구도 유지해 일반 resolver와 호환합니다. 중지·실패·충돌 복구에서 MINER 소유 내용이 일치하는 파일만 제거하고, 외부 변경이 있으면 보존·오류 표시합니다. 이전 버전의 DNS 복구 기록도 처리합니다.
- launchd 도우미의 umask 077에서도 DNS 데몬이 읽을 수 있도록 새 resolver 디렉터리는 0755, 파일은 0644로 생성합니다. 기존 디렉터리 권한을 임의로 변경하지 않습니다.
- Mac 앱의 Riot PASS는 WARP 상류 접속에 더해 **OS의 가상 주소 조회 → 선택 TUN → WARP 경유 DNS·실제 IP 연결 → 검증된 TLS 응답**도 통과해야 표시합니다. 실제 주소가 반환되면 연결하지 않고 `CLIENT_OS_DNS_BYPASS` 경고로 구분합니다.
- 실제 Riot 프로세스의 업데이트 요청·로그인·친구 목록·매칭 알림 성공을 검사한 것은 아닙니다. 고정 인증 서버 한 곳의 OS 경로 검증입니다.
- 진단 2.0.4는 설정상 구성 요소 관측과 실제 OS DNS 선택을 구분하고 Mac Riot Client/Helper 이름도 소켓 집계에 포함합니다. 원본 진단·사용자 주소·토큰은 배포하지 않습니다.
- Preview 6의 WARP 경유 암호화 DNS·실제 IP 연결, 게임 중 수동 전환, 기존 세션 무중단 이전을 보장하지 않는 정책을 유지합니다.

## 검증

소유 resolver 생성·보존·부분 실패·복구·권한 검사와, 상류 성공이어도 OS DNS 경로가 잘못되면 PASS를 내보내지 않는 검사를 포함합니다. Mac 네이티브 선택 TUN 시험에서는 실제 OS 조회와 TLS 응답까지 확인합니다. TLS 응답 서버는 무해한 로컬 fixture와 시험용 CA이며, 프로덕션 TLS 검증을 끄지 않습니다. 실제 WARP·학교망·Riot 업데이트 성공은 별도 사용자 기기 확인이 필요합니다.

이번 앱 배포는 Mac Apple Silicon/Intel DMG입니다. Windows 공통 회귀 검사는 수행하지만 새 Windows EXE는 포함하지 않습니다. main·ALPHA·Homebrew·이전 릴리스를 덮어쓰지 않습니다.

## 설치

기존 MINER에서 정상 중지·복구 완료 후 종료하고 새 앱을 시스템 `/Applications`에 교체합니다. Preview 7을 확인하고 시작하세요. 새 도우미 설치 때 한 번 관리자 승인이 필요할 수 있습니다. Riot 클라이언트를 매번 종료하라는 차단은 없지만, 이미 열린 연결·앱 내부 캐시를 강제로 이동·삭제하지는 않습니다. 연결 후 도구 → WARP 연결 확인 및 Riot 클라이언트의 다시 시도를 사용하세요.

기존 도메인 resolver 설정과 충돌하면 삭제하거나 덮어쓰지 말고 오류를 확인하세요. 이전 앱으로 돌아갈 때도 먼저 Preview 7에서 중지·복구를 완료해야 합니다. Developer ID 설정이 없으면 ad-hoc 서명·미공증입니다.
