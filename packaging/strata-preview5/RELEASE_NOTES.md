# MINER STRATA 2.0.0 Preview 5 — 게임 중 수동 연결 변경

게임 프로세스가 실행 중이라는 이유로 MINER 시작을 막던 검사를 제거했습니다. 게임·클라이언트를 강제 종료하지 않고 사용자가 요청한 시작을 진행합니다. Mac은 전환 시 재접속이 필요할 수 있다는 안내를 진단 로그에 남깁니다. 별도 확인창으로 막지 않습니다.

- 연결 중이라면 **중지 → 복구 완료 → 시작**, 이미 중지됐다면 **시작**을 누르세요.
- 작업 중 중복 시작, 복구 실패 상태, 엔진 소유권 검사는 유지합니다. 기존 엔진 정리 전에 새 엔진을 겹쳐 시작하지 않습니다.
- 경기 단계에 따른 자동 WARP 전환은 추가하지 않았습니다. 전환은 사용자 조작에만 수행합니다.
- 기존 TCP/UDP 세션은 자동 이전되지 않습니다. 게임 재접속은 게임 클라이언트에서 진행해야 할 수 있으며 성공·무중단 전환을 보장하지 않습니다.
- Preview 4 DNS 보완과 진단 2.0.2는 유지합니다. 친구 상태·매칭 수락창 문제의 원인을 확정하거나 해결했다고 주장하지 않습니다.

Mac Apple Silicon/Intel DMG를 별도 배포합니다. Windows 공통 검사도 같은 정책으로 변경·테스트하지만 이번에 Windows EXE는 새로 배포하지 않습니다. main·ALPHA·Homebrew·기존 배포는 보존합니다.

검증은 실제 게임 대신 무해한 게임/클라이언트 이름의 대기 프로세스로 패키징된 CLI가 시작을 허용하고 재접속 안내 코드를 반환하는지 검사합니다. 실제 게임 전환·재접속 결과는 미검증입니다. 기존 일반 실행·DMG 설치·업데이트·선택 경로·복구 검사도 통과해야 게시됩니다.

설치할 때는 MINER만 정상 중지·종료하고 DMG의 MINER.app을 시스템 `/Applications`에 교체합니다. 설치 후 About에서 Preview 5를 확인하세요. Developer ID가 설정되지 않았다면 ad-hoc 서명·미공증입니다.
