# MINER Diagnostics 2.0.2 — 클라이언트 실시간 연결 조사

MINER 앱 업데이트가 아닌 별도 읽기 전용 진단 도구입니다. 이번 버전으로 친구 상태·매칭 수락창 문제를 해결했다고 주장하지 않습니다. 실제 오류가 발생한 기기의 연결 자료가 있어야 원인을 좁힐 수 있습니다.

- LoL/Riot 클라이언트의 TCP 소켓 상태를 역할·포트 종류·가상 주소/실제 주소/loopback으로 집계합니다. Mac은 현재 사용자, Windows는 현재 세션의 이름이 일치하는 프로세스만 조회합니다. 게임·일반 브라우저 소켓은 수집하지 않습니다.
- 실제 주소, 프로세스 ID, 경로, 실행 인자, 계정, 토큰, 친구 목록, 메시지, 패킷은 내보내지 않습니다. lockfile·로그인 자격 증명을 읽거나 클라이언트 API를 호출하지 않습니다.
- 수락창 누락·온라인/오프라인 불일치·파티 오류를 USER_REPORT로 구분합니다. TCP ESTABLISHED 및 포트 이름은 실제 채팅 로그인·알림 수신 성공을 증명하지 않습니다. 조회 실패는 연결 없음으로 해석하지 않습니다.
- SOCKS CONNECT 거부가 미분류 오류로 사라지던 진단 분류를 보완했습니다.
- 네트워크·DNS·WARP 모드 변경, 클라이언트 종료, 자동 수락, 자동 업로드는 없습니다. 외부 능동 검사는 기존처럼 별도 선택입니다.

Mac은 ad-hoc 서명·미공증, Windows는 미서명입니다. Mac CI는 무해한 LeagueClient 이름의 loopback 연결 fixture를 패키징된 도구로 관측하는 검사를 포함합니다. 실제 Riot 접속 시험은 아닙니다.

## 기록 방법

ZIP을 풀고 터미널에서 `./MINER-Diagnostics --interactive`를 실행합니다. 외부 검사에는 기본 N으로 답해도 됩니다. 같은 창에서 정상 로비의 2(연결 후), 문제가 난 직후 6(오류)을 기록한 뒤 증상을 선택합니다. WARP·클라이언트를 재시작하기 전에 기록하고 0으로 저장하세요. 실제 랭크 게임을 시험용으로 시작할 필요는 없습니다.

수락창이 사라진 현재 상태를 한 번만 기록하려면:

```bash
./MINER-Diagnostics --phase error --client-event ready_check_missing
```

온라인/오프라인 불일치에는 `--client-event presence_mismatch`를 사용합니다. 바탕화면에 생성한 진단 ZIP을 검토한 뒤 직접 공유하세요.
